# 0.9.0：应用内更新与公开发布渠道

本版加入公开 GitHub 更新检测、流式下载、文件与安装包身份校验、系统安装入口，以及开发仓库到公开发布仓库的自动构建流程。使用方式与部署配置见 [AUTO_UPDATES.md](AUTO_UPDATES.md)。

首次仍需手动安装包含更新功能的新版；此后在电视端确认系统安装即可，不再逐次传 APK。播放和后台期间不执行更新请求，覆盖安装保留本机记录。电视不保存 GitHub 凭据。

## 本地验证

- JVM 测试 83 项通过，包含新增的更新版本规则、路径限制、大小上限、截断下载、超长下载、摘要错误、取消清理与缓存校验。
- Release lint：0 错误、30 警告。正式签名构建成功，最低 Android API 26。
- TV 模拟器覆盖安装后，原收藏与续播记录保留；更新窗口默认聚焦检查按钮，请求完成后焦点保留，自动检查开关可达，关闭窗口回到版本设置项。
- 未发布 `update.json` 时，公开下载地址返回 404，客户端显示「尚无可用的自动更新版本」，可再次检查，不影响内容浏览。
- 720p / 1.5 倍字体下检查按钮可达；真实 HTTPS 检查后切换字号、恢复普通字号及退出无崩溃。更新连接池的 TLS 关闭放到后台，避免系统重建 Activity 时触发主线程网络限制。

## 接入状态

公开仓库 `N3urda/hongguoTV-updates` 已创建。自动签名与源代码同步还需要授权配置 Actions Secrets 和专用部署密钥；在 `TV_UPDATES_ENABLED` 未设为 `true` 前，同步工作流跳过。

因此，这份记录不宣称已完成真实公开新版下载、系统安装授权、覆盖更新或云端自动发布的端到端验收。完成凭据配置后，应以实际云端 Release APK 和电视安装结果补充验证。

Android 8 实体电视的系统安装器、未知来源设置、网络、解码和长期稳定性仍需实机确认。
