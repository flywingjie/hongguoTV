# Kotlin TV 0.4.0

基于远程 `7d76463`，包名 `com.hongguotv.nativeapp`，versionCode 4，最低 Android 8.0 / API 26。仍为独立 APK，无需 Docker 或另外部署服务。

## 功能

- 播放故障恢复：临时网络/资源读取错误最多自动重试 3 次，间隔 1 / 2.5 / 5 秒；没有可用网络时等待网络恢复，不消耗次数。重新请求播放地址，保留集数、位置和播放/暂停意图。提供立即重试、停止自动重试、720P 与返回选集；离开前台取消自动重试。解码错误不反复发起网络重试，并启用设备可用解码器初始化回退。
- 播放中选集：侧边面板默认聚焦当前集，每组 20 集，支持数字定位、首末组禁用和方向键导航；确认新集才换集，取消恢复原播放状态和焦点。打开面板临时暂停，不退出播放器。
- 首页一键续播：显示最近 3 部没有手动标记整剧已看的剧；按剧集 ID 匹配最新列表，已播完当前集则进入下一集。源列表移除原集时从首集开始，已到最后一集时从末集开头开始。推荐加载不阻塞本机续播入口。
- 收藏剧更新提示：前台启动检查超过一小时未检查的收藏，可手动刷新。首次建立基准，此后显示新增集数与当前总集数；进入详情后确认已查看。检查失败保留旧结果，串行请求，单请求 12 秒，连续 3 部失败停止本轮检查。应用退后台后不再启动后续检查；已在途请求可能运行到超时。无后台推送，不是红果账号同步。
- 全局默认清晰度与倍速：设置提供 480P / 720P / 1080P、0.75 / 1 / 1.25 / 1.5 / 1.75 / 2×，沿用旧设置并持久化。清晰度按片源可用档位选择；播放中修改会保存为全局默认，切清晰度保留位置与暂停状态。

## 验证与边界

- 正式签名构建、40 项 JVM 测试通过；Release lint 0 error / 19 warning。核心测试覆盖续播 ID 重排/缺失/末集、有限重试、配置兼容、收藏首次基准/累计新增/确认/回退/过期响应/损坏数据。
- Android TV API 36 ARM64 模拟器，默认 1080p 与 720p / 1.5 倍字体；方向键打开侧边选集，定位并选择第 788 集，检查末组边界与取消焦点。首页直接进入播放，全局配置跨重启保留。
- 使用模拟器系统提供的单应用网络阻止功能制造真实 SocketTimeoutException。发现并修复恢复联网权限后不自动重试的问题，补充网络阻止状态回调；修复后记录 `Automatic playback recovery 1/3 at 7751ms`，恢复到相同的 00:07 暂停位置，480P / 1.5×。测试后还原系统网络配置。
- 收藏新增场景使用明确的合成旧基准 785 集，正式 APK 从真实接口读取 788 集，展示新增 3 集；重启保留，进入详情后清除。它证明检测链路，不声称测试期间平台实际发布了三集。临时开发包只用于写入模拟器测试基准，观察前恢复正式 APK，开发包不交付。原测试记录在结束时恢复。
- 大字号截图检查发现收藏卡片的总集数被省略，最终 APK 将收藏更新说明改为两行，并重新验证完整显示。验证包包含功能测试版本及最终文字换行修复版本的明确 APK 哈希对应关系；不会将中间失败记录当作通过证据。
- 记录的 UI XML 可通过 `python3 kotlin-tv/tools/verify-watching-evidence.py <tv目录>` 复核；这不是自动驱动遥控器的测试，也不替代截图目视检查。

尚未验收 Android 8.0 实体电视解码/音频、长时间稳定性及各品牌系统差异。网络恢复的真实注入覆盖已暂停场景；三次上限由核心测试及调用路径检查验证。账号登录和平台同步仍未接通。
