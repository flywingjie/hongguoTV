# Kotlin 0.8.0：安静连播与竖版海报界面

最低 Android 8.0 / API 26，versionCode 8。单 APK，安装后联网使用，无需额外服务。沿用发布签名，可覆盖安装 0.7.0 并保留本机收藏、观看记录和设置。

发布页：[kotlin-v0.8.0](https://github.com/N3urda/hongguoTV/releases/tag/kotlin-v0.8.0)，安装包 `hongguotv-kotlin-0.8.0-android8.apk`。

## 播放交互

- 首次开播、手动换集、自动连播不再自动弹出标题与进度浮层。播放器 READY 和播放状态回调只更新已经显示的浮层，不主动把隐藏浮层重新打开。缓冲转圈、播放失败和定时停止等必要反馈仍保留。
- 暂停、快进快退、向上或菜单键是主动操作，会显示对应信息或控制。正常播放时浮层仍可自动收起。
- 进度条或更多控制可见时，返回键先收起整个浮层，保持播放或暂停状态与进度；再次返回才退出。从首页直接续播退出回原卡片，从详情播放则回详情。
- 向下打开选集后取消，恢复打开前的浮层可见性，不额外弹出进度条；保留原有播放或暂停状态。

## 海报与界面

- 实际读取 8 张接口原图：1 张 640×915、7 张 640×914，约为 7:10。首页和列表采用六列竖版海报；首页、列表、详情均完整等比显示图片。
- 修复图片解码阶段的居中裁切。现在先按目标尺寸采样，再等比缩放完整原图；不同长宽比的图片会留边，不拉伸。大字号下按可用高度缩小海报，给标题和状态留空间。
- 统一深色背景、暖白文字、珊瑚色焦点和圆角剧卡。正常字号时首页内容类型并入导航；放大字号时单独成行。选中剧的信息固定在上方，切换分区时对齐标题和整排剧卡。
- 设置按「播放偏好」「片单与设备」分为两组，左右切换同排选项，上下切换组内条目。保持全局默认清晰度、倍速、画面模式和自动连播的保存行为。
- 保留 0.7.0 的分页、图片队列/缓存预算、后台存储、播放器复用和临近片尾预加载。界面使用原生控件和简单图形，没有加入模糊背景、焦点动画或新图片框架；本轮不作新的性能提升比例承诺。

直接覆盖安装，无需先卸载。APK、源码和验证资料均在本版 Release。
