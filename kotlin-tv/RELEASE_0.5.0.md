# Kotlin TV 0.5.0

基于远程 `3c2acd7` 继续迭代，包名 `com.hongguotv.nativeapp`，versionCode 5，最低 Android 8.0 / API 26。仍为独立 APK，无需部署第二套服务。

## 这次补齐的功能

- 定时停止：播放菜单提供 15 / 30 / 60 / 90 分钟、本集播完、再播完 3 / 5 集。按实际经过时间计时，暂停也计时；按集数仅在片尾计数，手动切集不扣次数。片尾先判断停止，再决定是否自动下一集。到点暂停、保存进度、取消自动恢复，释放保持亮屏；按播放可继续。仅本次观看有效，退出播放器或切到后台取消。
- 手机备份与恢复：设置中显示同一局域网二维码，浏览器下载或上传本原生版 JSON 备份，包含收藏、观看进度、已看标记、搜索历史和全局设置。上传不直接写入，电视展示数量、默认聚焦取消，确认才合并。已有收藏优先，进度按时间保留较新记录；默认不覆盖全局设置，勾选后才恢复。最多 500 部收藏、200 条最近观看、20 条搜索；2 MB 文件限制。
- 全局画面模式：完整画面（默认）、等比铺满、拉伸铺满，播放中立即切换并持久化，选择时说明裁切字幕或改变比例的影响。
- 系统媒体控制：前台播放器发布剧名、集数、时长、位置和状态，响应播放、暂停、上下集、定位和停止。后台会话停用，不增加后台播放服务。视频加载期间收到的暂停不会被后续加载覆盖；选集面板中暂停后，取消面板不会误播放，播放按钮同步显示实际状态。

备份 HTTP 窗口使用随机 128 位地址，最长 5 分钟；检查 Host、Origin、路径、请求大小和 JSON 结构，限制连接读取时长，关闭窗口/进入后台终止监听和在途连接。每个二维码仅下载一次，成功上传后关闭会话，仍需电视确认。文件不包含平台登录凭据，也不提供红果账号同步。

- 50 项 JVM 测试全部通过；正式 Release 构建、lint 通过（0 error / 23 warning，主要为依赖更新提示、已有平台属性与文字本地化提示）。新增测试覆盖定时到点/片尾/取消/切换，备份合并新旧进度和上限，错误格式/重复记录/深层 JSON，HTTP 单次传输、来源校验、超限拒绝、超时及关闭。
- Android TV API 36 ARM64 模拟器覆盖安装正式 APK，保留已有收藏和进度。通过遥控器验证播放菜单、三种画面选项、定时选择、片尾停止拦截下一集、系统媒体播放/暂停/上下集/停止、切集立即暂停、选集面板暂停后取消、退后台会话停用和取消定时。
- 正式 APK 真实 HTTP 导出再导入测试数据，验证电视取消不写入、合并较新进度、默认保留设置、勾选后恢复设置及重启保留。传输通过模拟器网络转发完成；真实手机扫码、路由器隔离策略和不同手机浏览器尚未验收。
- 默认 1080p 与 720p / 1.5 倍字体截图检查，新按钮和弹窗可通过方向键到达。按分钟的到点边界通过注入单调时钟的核心测试验证，没有声称连续等待了 90 分钟；安装包实际验证片尾定时停止。
- 回归发现并修正 JVM JSON 与 Android JSON 浮点重载差异；未将早期导出失败当作通过证据。验证包记录各批截图对应的 APK 哈希，最终 APK 复测播放、定时和导入导出主链路。另修复了短暂退后台后定时按钮仍显示旧倒计时的问题。
- 保存的 UI XML 可运行 `python3 kotlin-tv/tools/verify-comfort-evidence.py <tv目录>` 复核；该脚本校验记录的证据，不是自动驱动 UI 的测试。

Android 8.0 实体电视解码、音频、实体蓝牙遥控器及长期稳定性仍需实机验收。红果/抖音授权与平台收藏进度同步仍未接通；本轮备份是本机数据迁移。
