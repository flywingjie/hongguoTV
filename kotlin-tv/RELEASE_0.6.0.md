# Kotlin 0.6.0：更直观的首页与更快的换集

最低 Android 8.0 / API 26，包名 `com.hongguotv.nativeapp`，versionCode 6。单 APK，联网即用，无需 Docker 或额外服务；沿用发布签名，覆盖安装 0.5.0 可保留本机记录。

## 本版变化

1. **首页按观看任务组织**：接着看、收藏有更新、稍后看、热门发现，各自横向选剧。空分区自动隐藏；接着看显示集数、时间和进度条，确认直接续播。收藏更新展示具体剧和新增集数，热门更多页保留原有分页。
2. **选剧信息随焦点展示**：首页及搜索/排行榜/收藏/历史顶部显示选中剧的剧名、接口提供的集数或热度、题材和简介，并补充已收藏、稍后看、观看位置等本机状态。长简介可进入详情展开。720p、1.5 倍字体下缩小封面，为文字留出空间。
3. **剧卡快捷操作**：长按确认或菜单键直接播放/续播、收藏、稍后看、查看详情；首页可隐藏热门推荐，设置可一键恢复。稍后看 100 部、隐藏推荐 500 部纳入备份，旧版备份缺少这些字段时仍可恢复。
4. **启动与切集优化**：首页元数据缓存 7 天，封面缓存最多 24 MiB，按焦点附近加载。后台新内容由用户确认替换，避免移动正在浏览的卡片。下一集在自动连播开启、非按流量计费网络、当前播放稳定且已缓冲至少 5 秒时预加载；只保留一个准备结果和最多 1 MiB 开头，2 分钟失效，不落盘。视频索引继续受原有 8 MiB 上限约束。切换清晰度、退出/后台或网络丢失/转为计费时取消；失败/过期/未完成走正常解析和恢复流程。

### 性能样本

同一最终 APK、同一 Android TV 模拟器中的小样本；不视为 Android 8 实体电视的性能承诺。首页计时从 Activity 创建到内容布局回调，包含列表，不代表所有封面下载完成；播放计时从切集到 Media3 READY，不是端到端首帧指标。

| 场景 | 实测 |
| --- | --- |
| 首页无缓存，1 次 | 853 ms |
| 首页有缓存，3 次冷进程启动 | 406 / 389 / 298 ms |
| 同集换集对照（第 5 / 6 / 7 集），已预加载 | 175 / 159 / 149 ms |
| 同集换集对照，未预加载 | 723 / 1140 / 950 ms |

预加载与普通路径交替验证，中间返回上一集后立即切回，以确保普通路径尚未触发预加载。所有 9 次换集完成，最终包播放日志没有 Android 未捕获异常。启动样本使用原模拟器实例；最终播放对照使用隔离实例和软件 GPU，表内每组前后条件一致。
