# Kotlin 0.7.0：面向低配电视的性能与交互优化

最低 Android 8.0 / API 26，包名 `com.hongguotv.nativeapp`，versionCode 7。单 APK，联网即用，无需 Docker 或额外服务；沿用发布签名，覆盖安装 0.6.0 保留本机记录。

发布目标：[kotlin-v0.7.0](https://github.com/N3urda/hongguoTV/releases/tag/kotlin-v0.7.0)，安装包名 `hongguotv-kotlin-0.7.0-android8.apk`。

## 本版变化

### 控制首页与列表的工作量

- 首页保留「接着看 → 收藏有更新 → 稍后看 → 热门发现」；前两行各最多 8 部，后两行各最多 10 部，超过后提供「查看全部」。收藏、最近观看及首页集合按每页 20 部显示，不再同时创建整份剧库的卡片。
- 焦点预览固定为一行剧名和一行状态，简介移到详情，避免长短标题切换带动下方布局变化。字体与封面仍适配电视及放大字号。
- 收藏、稍后看、隐藏操作更新当前卡片区域，保留每行横向滚动位置；删除当前卡后聚焦相邻卡。返回列表时恢复页码和位置，并确保焦点可见。

### 减少主线程读写与旧请求

- 启动在后台读取本机记录，建立收藏、历史、设置等内存索引。焦点与卡片状态查询使用索引，避免每次移动焦点都解析和排序整份 JSON。
- 变更按字段合并，序列化和存储在后台串行完成。首页缓存独立存储，旧版缓存兼容迁移；暂停、退出等生命周期变化请求及时写入，避免在主线程等待磁盘。突然断电或强制结束进程仍可能丢失最近尚未落盘的修改。
- 页面内容请求有独立取消范围，快速切换搜索、翻页或退出时取消过期请求；返回的旧结果不覆盖新页面。
- 图片采用独立请求队列，按实际显示尺寸采样和裁切。焦点附近图片优先；排队最多 24 项，低内存设备使用 1 个工作线程和 4 MiB 内存缓存，其他设备使用 2 个线程和 8 MiB。保留 24 MiB 磁盘缓存；离场解绑旧视图并取消请求，进入播放和后台时清理图片缓存。

### 降低换集和预加载成本

- 普通换集复用 Media3 播放器与播放视图，切换媒体源并更换本集监听，旧集回调不能更新新集状态。故障恢复、退出播放与进入后台仍完整释放播放器。
- 保持播放缓冲为 15–30 秒、目标 12 MiB；该目标不是应用总内存上限，解码器、界面和媒体索引仍各自占用内存。
- 下一集改在临近片尾时准备：按当前倍速估算剩余时间，最后 30 秒内且自动连播开启、网络非按流量计费、当前播放稳定和缓冲充足时触发。每集最多尝试 3 次，尝试间隔至少 15 秒。
- 仍只保留一个准备结果和最多 1 MiB 开头数据，2 分钟失效，不保存整集视频。清晰度、网络或生命周期变化时取消；未命中、过期或失败走普通加载流程。
- 隐藏的播放信息不逐秒改写，媒体会话按状态、定位、倍速等事件更新；进入后台停止界面计时任务。

- 过滤已知无法显示视频的 ByteVC2 资源，优先选择设置范围内的兼容清晰度；若只有更高清晰度可用，使用最低的兼容档并显示「兼容资源」，不改动全局设置。READY 时还会检查视频轨道，防止仅音频正常却一直黑屏。

### 减少遥控器步骤

- 最近观看、首页接着看和收藏更新确认即续播；退出后回原列表。从详情开始观看则回详情。
- 播放时「↓」直接打开选集侧栏；「↑ / 菜单键」打开播放、上下集、倍速、清晰度等更多操作。选集仍每组 20 集，取消保留原播放或暂停状态。
- 首页集合有可通过遥控器到达的返回入口；翻页、移除卡片和切换内容类型保持页面状态与焦点一致。

### 启动与换集计时

- 3 次冷进程启动，保留磁盘首页和封面缓存：Activity `TotalTime` 为 231 / 166 / 338 ms；应用内从创建到首页内容布局回调为 140 / 109 / 269 ms。不是全新安装无缓存启动，也不是按键到全部封面完成的时间。
- 同集视频首帧对照：第 6 集预加载 135 ms / 普通 800 ms，第 7 集 166 / 585 ms，第 8 集 139 / 779 ms。计时从 `playEpisode` 入口（保存和旧资源处理之前）到 `onRenderedFirstFrame`，而非 READY。包括 3 次回上一集的 9 次切集都取得首帧。
- 以上是软件 GPU 模拟器和当时网络的小样本，不代表实体 Android 8 电视的解码速度、掉帧率或长期稳定性。低内存图片配置依据设备 `isLowRamDevice` 分类启用，未用该模拟器强制覆盖所有设备分支。

Release 的验证 ZIP 含最终 APK 对应截图、首帧日志、备份断言、内存采样、测试和 lint 报告；其中 `verification.json` 记录源码提交，`SHA256SUMS` 校验各附件。验证脚本检查保存证据的一致性，不替代实机验收。中间 APK 的失败样本、测试辅助 APK、备份会话令牌与本地签名材料均不打包。

## 安装与边界

下载 `hongguotv-kotlin-0.7.0-android8.apk` 后覆盖安装，不必卸载。源码、最终验证资料和文件校验信息以本版本 Release 附件为准。

最低 API 26 配置不代表 Android 8.0 实体电视已经验收；其芯片解码、音频输出、遥控器和长时间稳定性仍需实机验证。低内存模式依据 Android 的设备分类启用，也不等同于所有老电视都会上报为低内存设备。

红果/抖音账号同步尚未接通，收藏、稍后看和观看进度继续保存在本机，可通过已有手机备份功能迁移。内容接口与网络可用性仍依赖第三方平台。
