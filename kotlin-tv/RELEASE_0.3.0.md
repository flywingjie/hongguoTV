# Kotlin TV 0.3.0 交付记录

基于远程 `cdbc7ee`（漫剧筛选、倍速与漫剧排行榜）继续开发，保留上述功能并提供新的正式签名 APK。包名 `com.hongguotv.nativeapp`，versionCode 3，最低 Android 8.0 / API 26。

## 新增

- 遥控器数字面板定位集数，范围校验，定位后聚焦对应剧集，确认才播放。取消回到原来的跳转按钮。
- 本机搜索历史：按漫剧/短剧类型保存，去重、最近优先、最多 20 条，重启保留；支持重搜及清空。
- 手机辅助输入：搜索页打开二维码，在同一局域网的手机浏览器输入剧名，电视直接搜索。APK 内临时监听，随机 128 位路径令牌，单次使用，最长 5 分钟，关闭窗口或退后台后停止。限制请求大小、输入长度，校验 Host 与提交来源，不接收账号凭据，不需要另外部署服务。
- 最近观看管理：管理按钮、卡片菜单键或长按确认进入；删除单条、清空、标记整剧已看/恢复未看。删除有确认与取消入口，收藏保留。整剧已看后的详情提供重新观看。
- 版本与更新：显示实际安装版本，扫码或电视浏览器打开 GitHub 发布页。私有仓库由用户在浏览器完成 GitHub 登录；APK 不内置 GitHub Token。这是下载入口，不是自动检查更新、下载安装器。

## 账号同步尚未接通

用户用抖音账号登录红果。普通抖音 OAuth 能力不能证明拥有红果收藏、观看记录和续播进度的授权；当前缺少经过验证的红果账户映射与数据读写接口，以及该应用的平台注册配置。本版不提供虚假的已登录状态，也不收集密码、Cookie 或验证码。详见 [账号同步调查](../docs/ACCOUNT_SYNC.md)。

## 验证

- `./scripts/build-kotlin.sh`：34 项 JVM 测试通过，Release lint 0 error / 13 warning，正式混淆 APK 构建成功。
- 新测试覆盖集数输入边界、搜索历史类型隔离/去重/损坏恢复，以及手机输入成功、单次提交、来源/Host/路径校验、畸形/超长输入、主动关闭和超时。
- 正式签名覆盖安装成功，保留原收藏和观看记录；发布证书延续 0.2.x。
- Android TV API 36 ARM64 模拟器：1080p 默认字号，以及 720p、1.5 倍字体。数字面板、手机输入、更新弹窗均经截图目视检查，动作按钮可达；39 组最终 APK 的截图/XML 随验证包提供。
- 遥控器输入 104，定位对应集并播放；无效的 0 保留面板并显示范围提示；取消回到跳转按钮。
- 通过 ADB 端口转发调用运行在 APK 中的实际局域网表单，提交中文“末日漂流”，电视加载真实漫剧结果。验证窗口关闭后原端口不可用；搜索历史重启后仍在，并能重搜。此项验证不等于实体手机与电视间的路由、Wi-Fi 隔离条件已验收。
- 标记整剧已看、取消删除、删除单条、清空模拟器测试记录均已验证；收藏在删除和清空后保留。
- 排行榜进入/返回恢复卡片，真实视频播放到 00:51 / 02:01，暂停后切换 1.5× 倍速，焦点回到倍速按钮。测试后恢复 1×。
- 30 条 UI XML 证据断言通过：`python3 kotlin-tv/tools/verify-convenience-evidence.py <验证包中的tv目录>`。该脚本检查已采集结果，不自动驱动遥控器，也不替代截图视觉检查。
- 过滤后的 AndroidRuntime:E、HongguoTV:W、ExoPlayerImplInternal:E 日志为空。本轮结束恢复默认分辨率、密度、字号并关闭测试模拟器。

Android 8.0 实体电视、真实音频输出、长时间播放和实体手机局域网连接仍需目标设备验证。账号登录/同步不在通过项中。
