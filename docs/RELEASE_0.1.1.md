# v0.1.1：TV 操作与展示适配

本版继续使用 React Native TV，最低 Android 8.0 / API 26，应用 ID 保持 `com.hongguotv`。Android versionCode 为 2，使用与 v0.1.0 相同的本地签名，支持覆盖升级，保留设置、收藏与观看记录。

## 下载与部署

[GitHub v0.1.1 Release](https://github.com/N3urda/hongguoTV/releases/tag/v0.1.1) 提供 APK、源码、Docker 部署包、验证证据与 SHA256SUMS。内容服务镜像为 `ghcr.io/n3urda/hongguotv-bridge:0.1.1`，提供 AMD64 / ARM64；本版服务协议兼容 0.1.0。

```sh
adb install -r hongguotv-0.1.1-android8.apk
```

使用根目录 Compose 时，将 `.env` 中 `HONGGUOTV_VERSION` 改为 `0.1.1`，然后执行：

```sh
docker compose --env-file .env pull
docker compose --env-file .env up -d
```

私有镜像需要 GHCR 登录；不便登录时可使用 Release 内的 Docker 部署包从源码构建。完整步骤见 [Docker 部署指南](DOCKER.md)。签名密钥不包含在源码或附件中，不要先卸载旧版。

## 改动

- 聚焦卡片时滚动到完整行，让海报、两行标题与边框进入可见区域；按剧集 ID 恢复详情返回后的焦点。
- 推荐、搜索分别保留会话内目录和分页；收藏、最近观看保留各自的浏览位置，返回不会无条件刷新首页。
- 品牌与导航合并为一行，增加首页续看入口；重要控件采用约 5% 的电视安全边距，字号与布局以逻辑尺寸计算。
- 详情默认选择开始播放 / 继续观看，精简公共页头；简介可展开，选集每组最多 20 集，返回详情定位最近播放的集数。
- 首页内容区域按返回先回顶部导航，继续返回可退出；播放器的更多操作面板先响应返回关闭。
- 视频保持原比例，保留自动连播、收藏、断点续播和独立播放暂停键。

## 遥控器

| 场景 | 操作 |
| --- | --- |
| 列表 / 详情 | 方向键移动，确认打开，返回回到上一级 |
| 视频主画面 | 确认直接播放 / 暂停，控制栏隐藏时同样生效 |
| 视频主画面 | 左右单击跳转 10 秒，长按连续跳转；保持原先的暂停状态 |
| 视频主画面 | 上键显示信息，下键打开更多操作 |
| 更多操作 | 方向键选择上一集、播放 / 暂停、下一集、返回选集；确认执行 |
| 更多操作 | 返回关闭面板，焦点回到视频主画面；再次返回退出播放 |

按键参考 [Android TV 播放控制](https://developer.android.com/training/tv/playback/controls)，导航参考 [Android TV 导航](https://developer.android.com/training/tv/get-started/navigation)。

## 本次验证结果

- TypeScript 检查通过；12 项自动化测试通过，0 失败。
- 双 ARM release APK 构建成功，minSdk 26、versionCode 2、v2 签名校验通过；证书与 v0.1.0 相同，模拟器已覆盖升级。
- 1080p 第二排聚焦卡片完整显示；第二页新内容加载后自动聚焦，进入详情再返回保持同一部剧和位置。
- 720p 下重复上下移动后焦点仍完整可见；1080p 的 1.3 倍字体下检查了列表和详情。
- 89 集样本可切换到 81–89 分组，并聚焦第 81 集；初次进入详情聚焦播放入口，播放退出定位当前集。
- 主画面确认单击暂停，左右单击 ±10 秒；长按右键 1.8 秒从 0:27 到 1:17，释放后仍停在 1:17，暂停状态保持。更多操作面板返回后焦点回到视频，控制栏隐藏时确认仍直接暂停。
- 搜索提交后焦点进入第一条结果，避免键盘关闭后回到无关导航。
- 首页卡片区按返回到顶部导航，再按返回退出到电视桌面。覆盖升级后原有收藏、服务地址和观看记录仍可读取。

## 验证边界

本版的具体构建、测试与模拟器证据随 Release 提供。模拟器为 API 36 ARM64，720p / 1080p 是同一模拟器的不同显示配置，不能等同 Android 8 实机验收。实际电视的解码、厂商遥控器、中文输入法、声音、长时间播放、真实 4K 输出及观看距离仍需要目标设备验证。

源码中 TV 状态和交互边界见 [架构说明](ARCHITECTURE.md)。Apple TV 仍为工程骨架，手机与 Web 客户端尚未交付。
