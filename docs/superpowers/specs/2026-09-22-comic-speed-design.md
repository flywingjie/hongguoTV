# 原生版漫剧筛选与播放倍速

用户要求：在 Kotlin 独立版加入倍速、短剧 / 漫剧切换，主要观看漫剧。

## 交互

- 推荐和搜索页显示「漫剧 / 短剧」。首次升级默认漫剧，以后记住选择；切换类型清空两页的旧结果、页码和焦点，保留关键词并按新类型重新搜索。
- 收藏和最近观看保留所有既有记录；类型只约束在线推荐、搜索。
- 漫剧首页展示平台漫剧热播榜，使用榜单真实分页；搜索使用已有签名接口的 `tab_type=19`。短剧保留现有入口、搜索 `tab_type=11`。
- 漫剧接口异常时展示错误和重试，不能回退到不区分类型的短剧搜索。
- 播放菜单增加「倍速 1×」，确认后打开单选框：0.75 / 1 / 1.25 / 1.5 / 1.75 / 2×。默认 1×，选择立即应用，保存到本机，跨集、重试和重启保持；状态行显示实际速度。关闭弹窗恢复倍速按钮焦点，暂停状态不变。
- 播放操作分两行放置，避免新增按钮挤出电视安全区域。

## 接口选择与边界

候选方式：按标题关键词过滤会漏选、误选；搜索「热门」的漫剧 tab 能返回分类结果，但不等同完整推荐；官网漫剧热播榜明确限定漫剧且有真实页数。因此首页采用榜单，搜索采用专用 tab。

2026-09-22 实测 `/rank/hot-comic-drama` 可用，返回 `mergeLoaderData` 脚本中的 content JSON；支持已有来源里的旧 `r` 脚本格式。移动端响应有时缺少延迟 JSON，此时用 jsoup 读取已渲染的榜单卡片和分页，并校验路由是漫剧、页码匹配。`/category/comic` 是旧漫画分类，不能把它误当作漫剧；`/category/comic-drama` 实测 404。

搜索保存接口返回的 search_id、passback、next_offset，供下一页使用。游标按类型、关键词、页码隔离，5 分钟失效，最多 100 条；重搜第一页清除同条件旧游标，防止跨搜索串页。漫剧翻页时游标过期或被淘汰则明确提示并回第一页刷新，不能退回已验证会重复的纯 offset 请求。

核心层新增类型、倍速选项和榜单解析，Android 层管理偏好、遥控器焦点和 Media3 播放参数。保留包名及收藏 / 历史格式；本轮不改变签名。

## 验证

核心测试覆盖榜单两种格式、URL 解码、分页终点、类型隔离、搜索错误不跨类回退、空结果、倍速合法值。运行 JVM 测试、Android lint、Debug APK 构建；联网检查漫剧两页、搜索、详情与播放资源。在可用模拟器上检查遥控器、切换类型、倍速及持久化；实体电视未执行的项目明确说明。
